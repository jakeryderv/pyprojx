# Real-world pyproject.toml corpus

Unmodified `pyproject.toml` files from open-source projects, pinned to the
commits below. Tests check them to catch false positives: every diagnostic is
recorded in a snapshot, so a new check that misfires on real projects shows up
in review. Each file remains under its project's license.

To add a file, save it here unmodified and add a row with the commit it came
from.
